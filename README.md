# Bright Future School — Complete Static Website

A responsive, multi-page school website built with HTML5, CSS3 and vanilla JavaScript. It is designed for GitHub Pages and does not require Node.js or a build step.

## Quick start
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or run a local static server from this folder (recommended): `python -m http.server 8000`.
3. Visit `http://localhost:8000`.

## Pages
Home, About Us, Academics, Facilities, Admissions, Student Corner, Results, Fee Structure, Gallery and Contact Us.

## Branding
The supplied brief mentions a yellow and blue school logo, but no separate logo image or admission poster was attached with the project brief. The `BF` mark is a temporary text-based placeholder. Replace it with the official school logo when available.

## Important limitations
- Admission/contact/fee forms validate in the browser and show a demo message. They do not transmit or save data.
- Student documents and result records are not connected. Do not publish private student information in this public static site.
- Fee amounts, curriculum/board, actual facility availability, social links and map embed have not been supplied; they are intentionally left as editable placeholders.
- RTE information is general only and subject to current government rules.
- No CBSE/RBSE affiliation is claimed.
